========================================================================
 ZOO TYCOON - COMPLETE COLLECTION  on a Mac (EASY INSTALLER)
========================================================================

This kit installs and fixes Zoo Tycoon on your MacBook. It is made for an
Apple Silicon Mac (M1/M2/M3/M4). Everything here is free.

There are now TWO ways to install:

  METHOD A (RECOMMENDED): Use the Mac version + No-CD patch (fully automated)
  METHOD B (PORTING KIT): Original Porting Kit method from before

We recommend METHOD A because it's simpler, doesn't need Porting Kit,
and the No-CD patch means you don't need to mount an ISO every time.


------------------------------------------------------------------------
 METHOD A - Automated Install from Mac Version (15 minutes)
------------------------------------------------------------------------

DO THIS ONCE:

Double-click:   0 - Install from Mac Version.command

IF macOS blocks it with a box saying it "cannot be opened because the
developer cannot be verified": right-click the file, choose "Open", then
click "Open" in the box that follows. That is a one-time approval, per
file. If it just opens normally, there is nothing to right-click - skip
this. The same applies the first time you double-click any .command file
in this kit.

You need the Mac version archive first. This is the one manual download:

  https://www.myabandonware.com/game/zoo-tycoon-complete-collection-dzx

Choose the "Mac" version and save this file to your Downloads folder:

     Zoo-Tycoon-Complete-Collection_Mac_EN_Repack.zip

The script will then:
  1. Find that archive (kit folder, or Downloads)
  2. Extract the disk image ZT-CE.dmg from inside it
  3. Mount it and copy the game to
       /Applications/Zoo Tycoon - Complete Collection
  4. Clear the quarantine attributes (xattr -cr) - this is what fixes
     "Zoo Tycoon is damaged and cannot be opened"
  5. Set the game window to 1280x832, windowed (see the note below)
  6. Ask you one question about the disc check (see the note below)
  7. Create a "Play Zoo Tycoon.command" on your Desktop - and, if you
     chose the Custom Patch or the No-CD patch, a direct "Zoo Tycoon"
     shortcut as well

After it finishes you can play straight away. If you chose option A or B,
just double-click "Zoo Tycoon" on your Desktop - no disc, no Terminal
window, nothing else to run.


NOTE - the disc check question (this is the important bit):

The Mac repack expects you to keep a fake "MARINE" disc image mounted.
On macOS 26/27 that no longer works: the OS tells Wine that a mounted
image is a generic disk, not a CD, so the game still asks for the
CD-ROM. Verified on a real machine - not a guess.

There is a community patch that removes the CD check WITHOUT damaging
the game. Download it first (140 KB):

  https://community.pcgamingwiki.com/files/file/3251-zoo-tycoon-complete-collection-custom-patch/

You may need to make a free account to download. Save it as:

     ZooTycoonCC_CustomPatch.zip

Put it in your Downloads folder or next to this kit. The installer
offers three choices:

  A (default when the patch zip is present)
               LuKeStorm Custom Patch. No CD step AND staff upkeep keeps
               working - the only option that gives both. This game is
               exactly the version it supports (v12.4.0.9). Fully
               removable using the instructions in its own Info.txt.

  B            No-CD patch. Starts fine, but the repack author and the
               MyAbandonware page both warn it stops zookeepers cleaning
               exhibits and maintenance workers repairing fences. The
               original is kept as zoo.exe.original, so you can switch
               back at any time.

  C            Keep the original files. Gameplay intact, correct choice
               on an older macOS - but on macOS 26/27 the game will keep
               asking for the CD-ROM.

We do not bundle the Custom Patch: it ships a copy of one of the game's
own files, so the installer rebuilds that part locally instead.


------------------------------------------------------------------------
 METHOD B - Porting Kit Method (Original)
------------------------------------------------------------------------

Use this ONLY if Method A fails for some reason.

  STEP 1 - Check the Mac first (1 minute)
    Double-click:   1 - Check My Mac.command

  STEP 2 - Install Porting Kit (10 minutes)
    https://paulthetall.itch.io/porting-kit
    Download "Porting.Kit-7.0.2-Apple Silicon.dmg", drag to Applications.

  STEP 3 - Install the Zoo Tycoon port (10 minutes)
    Inside Porting Kit: Games -> All games -> Search "Zoo Tycoon" -> Install

  STEP 4 - Get the game disc image (10 minutes)
    https://www.myabandonware.com/game/zoo-tycoon-complete-collection-dzx
    Download Windows version -> ISO -> unzip -> keep ZOO_TYCN.iso in Downloads

  STEP 5 - Check again (1 minute)
    Double-click:   1 - Check My Mac.command

  STEP 6 - Fix it and play (2 minutes)
    Double-click:   2 - Fix and Play.command


------------------------------------------------------------------------
 PLAYING IT AGAIN LATER
------------------------------------------------------------------------

You do NOT have to run the installer or the .command files every time.

If you chose option A (Custom Patch) or B (No-CD patch), the game needs
no disc at all - just open it, any of these ways:

  - double-click "Zoo Tycoon" on your Desktop (direct shortcut)
  - open the "Zoo Tycoon - Complete Collection" folder in Applications
    and double-click "Zoo Tycoon"

"Play Zoo Tycoon.command" also works, but it is only really needed if you
chose option C (original files) - there it mounts the fake disc image the
original game expects, so use it each time.

METHOD B: use "2 - Fix and Play.command" from this folder each time. It
mounts the disc and starts the game.


------------------------------------------------------------------------
 IF SOMETHING GOES WRONG
------------------------------------------------------------------------

Re-run the relevant script and send the whole text of its window
to the person who gave you this kit. Every step is labelled [ok],
[DONE], [warn] or [FAIL], so the output tells us exactly where it
stopped.

Most common issues:
- "App is damaged": Run the installer again, it clears quarantine.
- "Please insert CD-ROM": The No-CD patch should fix this. If not,
  make sure MARINE.ISO is inside the app's Contents/Resources folder.
- Gatekeeper blocks the .command file: Right-click -> Open -> Open.


------------------------------------------------------------------------
 WHAT THE FIXES ACTUALLY ARE (for the curious / for a helper)
------------------------------------------------------------------------

METHOD A (Mac version wrapper - verified working):
  - The Mac repack is a ZIP holding one file: ZT-CE.dmg
  - Inside that image: a hidden ".Zoo Tycoon.app" (the real Wineskin
    wrapper, 1.6 GB, engine WS11WineCX21.1.0) plus a small helper app
    "Zoo Tycoon.app" that mounts a fake MARINE image and launches it
  - xattr -cr clears the quarantine attribute that makes macOS report
    "Zoo Tycoon is damaged and cannot be opened"
  - The disc check cannot be satisfied on macOS 26/27 by a mounted
    image, so the No-CD zoo.exe is used; the original is preserved as
    zoo.exe.original so the change is reversible

METHOD B (Porting Kit port - 4 bugs fixed):
  1. Porting Kit installs "cnc-ddraw" as the DirectDraw driver. It has no
     DllGetClassObject export, so any game that requests DirectDraw through
     COM fails instantly. Replaced with Wine's own builtin ddraw.
  2. Porting Kit's engine ships without LC_RPATH entries, so Wine cannot
     load its own libinotify or the libMoltenVK graphics backend. A cold
     start dies before the game starts. Fixed with install_name_tool.
  3. The game demands an 800x600 fullscreen mode, which Retina displays do
     not offer. zoo.ini is set to run windowed at 1280x832 instead.
  4. A leftover "gdi" DirectDraw renderer setting blocks the Direct3D the
     game needs, so it is removed.

Nothing outside the game app is touched: no system files, no admin
password, no permanent background processes.
